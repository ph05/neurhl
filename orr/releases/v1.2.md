# ORR 1.2: player-level in-season

*Released 2026-10-01. In-season forecasts from this date use 1.2: `python3 -m orr.inseason` (default `--model 1.2`; `--model 1.1` and `--model 1.0` reproduce earlier versions). The frozen 2026-27 preseason file is unchanged.*

## Why

Up to 1.1, ORR updated team ratings in-season, but every skater's per-game rates stayed at their preseason values all year. A player who scores 20 goals in 30 games kept his preseason rate in the game-day player lines. Live inputs also came only second-hand, from NeurHL's committed files.

## What is new

| Feature | What it does | Evidence |
|---|---|---|
| In-season skater rates (`orr/player_update.py`) | Updates goals, assists and shots per game with the player's games so far: rate = (n0 · preseason rate + count) / (n0 + games). | Walk-forward backtest below |
| Box-score ingest (`orr/ingest.py`) | Stores every finished game's per-player box score from the NHL API: TOI, goals, assists, shots, starting goalie, shots and goals against. | Parser unit-checked on the API's `playerByGameStats` schema. It runs live only where the API is reachable (the daily GitHub Action). |
| Version switch | `inseason --model 1.2` is the default. Run files record the model and its settings. | `test_inseason`, `test_player_update` |
| CI | `.github/workflows/orr_tests.yml` runs every test suite on each push that touches `orr/`. | |
| Changelog page | `docs/orr/changelog.html`, built from `orr/CHANGELOG.md`. | |

## Evidence: in-season skater rates

`orr/backtest/player_update_bt.py` (`orr/output/backtest/player_update_bt.json`):
- **Prior.** ORR's strict preseason projection for each season (first-10-game rosters, nothing else from the season).
- **Checkpoints.** After 25%, 50% and 75% of the season's games, each skater's rest-of-season goals and assists per game are predicted.
- **Scoring.** Each prediction is multiplied by his actual remaining games, so only the rates are judged, and compared with what he did. Skaters with 10 or more remaining games are included.
- **Tuning.** n0 was chosen from {10, 20, 40, 80, 160, 320, ∞} on 2012 and 2014-2017 only. 2018-19 confirm. The test (2021-22 and 2022-23, the last seasons with complete box scores) ran once.

| Window | Rows | Rest-of-season points MAE, updated | Preseason rate only | Shots MAE, updated | Shots, preseason |
|---|---|---|---|---|---|
| Tune 2012-17 | 9,266 | 3.779 | 4.075 | 9.32 | 10.82 |
| Confirm 2018-19 | 3,835 | 3.937 | 4.282 | 9.48 | 10.56 |
| **Test 2021-23** | 3,987 | **4.070** | 4.483 | **9.23** | 10.71 |

- **Test difference:** −0.413 points, 95% CI −0.487 to −0.344, from a paired bootstrap over player-checkpoints.
- **Chosen prior weights:** goals 40 games, assists 40, shots 20.

## Limits

- **Live box scores need the NHL API.** The build container cannot reach it, so updated rates appear once the daily Action runs from the default branch, or wherever `orr.ingest` can reach the API. Without box scores the player lines fall back to the preseason rates, exactly as in 1.1.
- **Only some rates update.** Goals, assists and shots per game update. Ice time, games played and dress probabilities do not.
- **Not yet calibrated.** The per-game P(goal) and P(point) are still Poisson in the updated rate. Their calibration is planned for 1.3.
