# ORR 1.3: the live loop matches the backtest

*Released 2026-10-01. Default in-season model: `--model 1.3`. Models 1.2, 1.1 and 1.0 remain reproducible. The frozen 2026-27 preseason file is unchanged.*

## Why

The backtests that validated ORR 1.1 used box-score lineups and starters for past games, plus goalie talent updated with each goalie's games so far. The live loop used NeurHL's pregame files for past games, which are sometimes wrong, and preseason goalie talent all season. 1.3 closes both gaps. It also checks whether 1.2's per-game player probabilities need correcting.

## What is new

| Feature | Switch | Status |
|---|---|---|
| **Box-score-first lineups and starters.** Past games use their actual dressed skaters and starting goalie, from the NHL box scores (`lineups.box_lineups`, `prefer_box`). Today's games still use pregame files. | `box_first` | On |
| **In-season goalie talent.** The backtests' own rule, `structural.goalie_talent_live`: preseason prior plus the season's saves above league average, weighted by shots. Each game uses only evidence from before its date. It feeds starter offsets in the filter's update and in today's forecast. | `goalie_update` | On |
| **Calibration of per-game P(goal) and P(point).** Scored against box scores; a Platt correction is available. | `player_calibration` | Code path on; correction **not adopted** (see below) |
| **Season to date on the website.** The skater table gains GP so far, points so far and projected rest-of-season points (updated rates times remaining team games) once box scores exist. | always | On |

## Evidence

**Goalie talent.** No new tuning was done. The rule and its settings (`ratings_hp.json` `goalie`: n0 3,000 shots, m0 −0.002, in-season weight 1.0) are the ones every in-season backtest since 1.0 used. With no box scores, the live talents equal the preseason table exactly; this is checked in the release run. `test_live_1_3` checks that talent moves the right way with saves and ignores games after the date.

**Player-game probabilities** (`orr/backtest/player_prob_bt.py`, run once):
- **Setup.** Rates are 1.2's: the strict preseason projection updated with the player's games so far. Probabilities are conditional on dressing.
- **Pre-declared rule.** Adopt the Platt correction only if it lowers test log loss for both outcomes.

| Outcome | Test skater-games | Mean predicted | Actual rate | Log loss, raw | Log loss, Platt (fitted 2012-17) |
|---|---|---|---|---|---|
| P(goal) | 92,313 | 0.152 | 0.155 | **0.39690** | 0.39709 |
| P(point) | 92,313 | 0.350 | 0.354 | **0.59726** | 0.59732 |

The raw Poisson probabilities are already calibrated: the test calibration slopes are 0.99 and 1.07. The correction makes both slightly worse, so it is **not adopted**. `params/player_prob.json` records `adopted: false`, and the live lines use the raw probabilities.

## Limits

- **Live box scores need the NHL API.** The daily GitHub Action provides them once merged. Until then 1.3 behaves exactly like 1.2, apart from the version label.
- **Today's games still depend on pregame lineup files.** The box-score-first change only affects games already played.
- **Goalie start shares do not update in-season yet.** Planned for 1.4.
