# ORR 1.9: is ORR beating NeurHL?

*Released 2026-10-02. Default in-season model: `--model 1.9`. Models 1.8 through 1.0 remain reproducible. The frozen 2026-27 preseason file is unchanged.*

## Why

The running accuracy table (1.5) showed each forecast's log loss on its own eligible games. Different forecasts are eligible for different games, so those numbers cannot be compared directly. There was no verdict, no check of the player probabilities against outcomes, no clinch or elimination information, and no warning if the daily run stopped.

## What is new

| Feature | Where | Notes |
|---|---|---|
| **Paired live comparison.** | `score.paired_vs_neurhl` → `scorecard_2027.json` `paired`; website "ORR daily vs NeurHL, same games" | Computed only on games where both forecasts were published before puck drop. It reports the mean difference with a paired bootstrap 95% CI and a verdict: "too few games" (fewer than 50), "ORR ahead" or "NeurHL ahead" (CI excludes 0), else "level". |
| **Live player-forecast reliability.** | `score.player_reliability` → `player_reliability`; website table | Daily P(goal), P(point) and P(3+ SOG), dress-weighted, are scored against box scores. A player absent from the box score scores 0. Reported as log loss and as predicted vs actual rate by bin. |
| **Clinch and elimination flags, magic numbers.** | `inseason.clinch_table` → standings file; website "Status" and "Magic #" columns | A flag is set when every simulated season agrees, for the playoffs, the division and the Presidents' Trophy. The magic number is the points a top-eight team needs to stay out of reach of the conference's ninth team. It ignores the wildcard format and tiebreaks, so it is a guide, not the official number. |
| **Freshness banner.** | Website header | Shows results-through date, latest forecast time and build time. It warns when the daily run is more than 36 hours old. |

## Evidence

No new tuning. `test_live_1_9` checks:
- that the paired comparison finds a known advantage and returns "too few games" below 50 games;
- that clinch and elimination flags and current points are computed correctly from a small synthetic table.

## Limits

- **Comparison panels are empty for now.** No ORR daily forecast has yet resolved on an eligible game: the 2026-10-01 results were not posted when 1.9 shipped. The panels fill as games and box scores arrive.
- **Approximate magic number.** It does not apply the wildcard format or tiebreaks.
