# ORR 1.7: what you see is current

*Released 2026-10-01. Default in-season model: `--model 1.7`. Models 1.6 through 1.0 remain reproducible. The frozen 2026-27 preseason file is unchanged.*

## Why

The website's standings and odds tables still showed the frozen preseason forecast, even after the daily runs began. 1.6's rest-of-season player intervals ignored games-played uncertainty and were untested. The Today table gave no schedule context, and no file said which ORR version made it.

## What is new

| Feature | Switch | Status |
|---|---|---|
| **In-season standings by default.** The standings and playoff-odds tables show the latest daily run (results so far fixed, the rest simulated); a View selector switches to the frozen preseason file. | always | On |
| **Calibrated rest-of-season intervals.** The 80% interval of a skater's rest-of-season points now simulates games played (binomial over the team's games left) and inflates the rate variance by v (`backtest/ros_interval_bt.py`, `inseason.players_ros`). | `ros_interval` | **On** (adopted) |
| **Rest and travel on the Today table.** Rest days (B2B, or 4d+ for a team's first game) and kilometres travelled for both teams, from the game model's schedule features. | always | On |
| **Version stamps.** The Today table and the daily-files list name the ORR version that produced them (from each run JSON); the changelog page opens with a version history linking every release note. | always | On |

## Evidence: rest-of-season intervals

- **Setup.** At 25%, 50% and 75% of a season, every projected skater's remaining points are predicted, using the strict preseason projection updated with his games so far (as in 1.2). The 80% interval is scored with the interval score (width plus 10 × the miss) and with coverage. Tuning used 2012 and 2014-2017 over v ∈ {1, 1.5, 2, 3}, with or without games variance. The test (2021-22 and 2022-23, 4,272 player-checkpoints) ran once.

| Configuration | Tuning score | Tuning coverage |
|---|---|---|
| 1.6: v = 1, fixed games | 25.04 | 0.64 |
| v = 1, games variance | 24.79 | 0.65 |
| v = 2, games variance | 23.59 | 0.70 |
| **v = 3, games variance** | **22.95** | 0.74 |

| Test | Interval score | Coverage |
|---|---|---|
| 1.6 | 28.29 | 0.62 |
| **1.7** | **25.53** | **0.73** |
| Difference | −2.76 (CI −3.07 to −2.43) | |

- **Decision.** Adopted under the pre-declared rule.
- **Two findings.** 1.6's intervals were far too narrow: 62% coverage for a nominal 80%. The chosen v = 3 sits at the edge of the grid, and coverage is still below nominal, so the grid is extended in 1.8.

## Limits

- **Still too narrow.** Rest-of-season intervals cover about 73%, not 80%. The remaining variance likely comes from role changes and injury spells, which a binomial games model understates.
- **Standings view.** The in-season standings view needs a daily run; before the first run it shows the preseason file only.
