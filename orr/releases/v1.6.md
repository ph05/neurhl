# ORR 1.6: the full picture

*Released 2026-10-01. Default in-season model: `--model 1.6`. Models 1.5 through 1.0 remain reproducible. The frozen 2026-27 preseason file is unchanged.*

## Why

1.5's running accuracy table read NeurHL's pregame forecasts from this branch's stale copy. The website showed goalies only as preseason projections. Teams had no measure of how hard their remaining schedule is. Players had rest-of-season numbers only as one website column, with no interval and no file.

## What is new

| Feature | Where | Notes |
|---|---|---|
| **Upstream NeurHL live files in the scorer** | `orr.score --neurhl-live <dir>`; the daily GitHub Action passes NeurHL's committed `neurhl/output/live/2027` | Every NeurHL pregame forecast is scored, not only those present when this branch was cut |
| **In-season goalie table** | Website goalie table | Adds GP, shots against and save % so far, preseason and updated save talent (1.3), and preseason and updated start share (1.4). Shown once box scores exist. |
| **Remaining strength of schedule** | `standings_<date>.csv` columns `sos_remaining`, `games_left`; website "SOS left" column | Mean net rating (o − d) of the opponents in each team's games not yet played, from the current filter ratings (`inseason.remaining_sos`) |
| **Rest-of-season skater file** | `players_ros_<date>.csv` each day, linked from the website's Files section | Season to date from box scores; rest of season = updated rates × expected remaining games; 80% interval of rest-of-season points from the conjugate negative-binomial predictive (`inseason.players_ros`) |
| **Fix: start shares** | `inseason.update_start_shares_live` | Teams with no box-score starts yet keep their preseason shares; 1.4's code renormalised them. The backtest was unaffected, because every team had starts at its checkpoints. |

## Evidence

No new tuning or test windows were used. Each feature is a direct computation from quantities already validated (filter ratings, 1.2 rates, 1.3 talent, 1.4 shares).

`test_live_1_6` checks:
- remaining SOS equals the mean of opponents' net ratings over the unplayed games;
- with no box scores, the rest-of-season file reproduces the preseason projection exactly, and its intervals bracket the mean;
- start shares of teams without observed starts are unchanged.

The website's new columns were render-checked with a temporary box-score file, at desktop and 390px width, in light and dark.

## Limits

- **Games played is not uncertain in the rest-of-season interval.** The interval covers rate and scoring noise only, so it is too narrow for players with uncertain games played. Calibrating it is planned for 1.7.
- **SOS units.** SOS is in rating units (log goal rate × 100), not points.
- **Live inputs needed.** The goalie columns, rest-of-season counts and live SOS need the daily GitHub Action's box scores and runs once merged. Today, SOS comes from the manual daily run.
