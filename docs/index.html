NeurHL projects the season from play-by-play up. Its predictions were committed on 25 September 2026, four days before opening night, and are scored in public as the games are played. The evidence behind each claim, including the claims that failed, is on this page.

What the evidence supports

A result counts as confirmed only if it came from seasons no decision had used, scored once after the model was frozen. Everything else is labelled for what it is.

  • Neural game network over event embeddings. Five configurations; the best (0.6966) finished level with a constant home-win rate (0.6898).
  • Embeddings as team strength. A 7.6-million-event transformer learns player type (position decodable at 95%), not team quality.
  • Rookie encoder. Validation error equal to predicting the mean at every season.
  • Event simulator for game odds. Blended with Elo it scored 0.6776 against Elo's 0.6767.
  • Absences, goalie quality, schedule density. Each added log loss to the game model.
  • Starting-goalie model. A goalie's share of starts to date predicts starters better.

How it was built and tested

Seasons were given roles before any model was fitted, and the scoring code refuses to cross them. Each season is labelled by the year it ends.

Training only Development Tune Confirmation, scored once Trains, never scores Live 2026-27

Rules that held throughout

  • Every input to a season's prediction comes from earlier seasons only.
  • Plans, gates and decision rules were committed before the numbers that tested them.
  • Searches were capped and every configuration was logged.
  • No betting-market data in any feature, target or selection step.
  • A causality audit corrupts all data after a cut point and requires earlier inputs to stay bit-identical.

What went wrong and was fixed

  • Two leaks let the event simulator see the next event; both passed the realism gates before an audit caught them.
  • A comparison of the season layer with a baseline used different seasons. On matched seasons the baseline is better.
  • Playoff ties were broken alphabetically, worth up to 1.6 playoff points for some clubs.
  • An exclusion rule was changed after results were visible. It is recorded, and results are reported both ways.
