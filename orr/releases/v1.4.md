# ORR 1.4: the standings race

*Released 2026-10-01. Default in-season model: `--model 1.4`. Models 1.3 through 1.0 remain reproducible. The frozen 2026-27 preseason file is unchanged.*

## Why

ORR's daily playoff and Cup odds had never been backtested in-season. Every earlier standings test scored the preseason forecast only. Goalie start shares were also fixed at their preseason values all year. 1.4 tests the in-season odds, calibrates them, updates start shares, tries to account for long-term absences, and charts the odds over time.

## What is new

| Feature | Switch | Status |
|---|---|---|
| **In-season standings backtest and drift calibration** (`backtest/standings_inseason_bt.py`). The rest-of-season drift is scaled by k, tuned on 2012-2017. | `standings_drift` | On, k = 0.5 |
| **In-season goalie start shares.** Each team's shares are updated with its box-score starts as a Dirichlet posterior mean, with α tuned on 2012-2017 (`backtest/start_share_bt.py`, `inseason.update_start_shares_live`). | `start_share_update` | On, α = 10 games |
| **Long-term absences in the rest-of-season simulation.** A player who dressed in 10+ games but missed the team's last N, and has not moved to another team, has his X1 lineup value removed from the team's future games (`lineups.absence_offsets`). | `absence` | **Off**: it failed its test (below) |
| **Playoff odds over time** on the website: every team's playoff odds by committed forecast, with one team highlighted. | always | On |

## Evidence

**In-season standings.**
- **Setup.** The filter is updated with the games so far at 25%, 50% and 75% of a season; the rest is simulated with completed games fixed. Final points are scored on the test seasons 2021-22 and 2022-23 (192 team-checkpoints, run once).

| Forecast | CRPS (points) | MAE | 80% coverage |
|---|---|---|---|
| **ORR in-season (k = 0.5)** | **3.84** | **5.47** | 0.86 |
| ORR in-season (k = 1) | 3.84 | 5.48 | 0.86 |
| Preseason forecast with results so far | 4.99 | 7.08 | 0.66 |
| Points pace | — | 7.07 | — |

| Checkpoint | In-season CRPS | Preseason CRPS | Pace MAE |
|---|---|---|---|
| 25% | 5.18 | 6.79 | 11.10 |
| 50% | 3.91 | 4.91 | 6.22 |
| 75% | 2.43 | 3.27 | 3.90 |

- **Drift.** Tuning CRPS barely moves across k ∈ {0, 0.5, 1, 1.5, 2, 3} (3.909 to 3.916); k = 0.5 was adopted as tuned.
- **Coverage.** The in-season intervals cover 86% on test, above the nominal 80%, so they are somewhat too wide. Planned for 1.5.

**Goalie start shares** (690 test team-goalie-checkpoints, 2021-23):
- Rest-of-season starts MAE: **5.29** updated vs 6.13 preseason.
- Difference: −0.83, CI −1.12 to −0.56.
- Tuned α = 10 games, from {2, 5, 10, 20, 40, 80, ∞}.

**Long-term absences.**
- **Tuning.** N = 20 was best of {5, 10, 20} on tuning, but still slightly worse than no offsets (3.914 vs 3.909).
- **Test.** +0.0008 CRPS, CI −0.009 to +0.010: no measurable effect.
- **Decision.** Under the rule declared before the test, the feature ships **off** (`params/standings_inseason.json`: `absence: false`).
- **Likely reasons.** The filter already absorbs a missing player's effect from the games he misses. The rule cannot see return dates. And at 25% of a season no team has enough games for the rule to act.

## Limits

- **Live inputs.** Start shares need live box scores, which the daily GitHub Action supplies once merged.
- **Over-wide intervals.** The in-season standings intervals are slightly too wide (86% coverage).
- **Sparse history chart.** The odds chart has one point per committed forecast, so it starts sparse.
